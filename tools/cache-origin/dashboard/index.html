What these numbers mean

Traffic covers cache artifacts, build mappings and publication requests found in retained logs. Dashboard views are excluded. Byte totals count successful GET response bodies; HTTP/TLS overhead and uploads are excluded. Average traffic rate divides those bytes × 8 by the observed wall-clock interval, including idle time. It measures traffic volume over time, not client download speed.

Log retention and collection outages can leave gaps. Statistics describe the available sample, not exact accounting. A request is not a distinct person or a complete build restore. Latency includes the transfer and is not time to first byte.
