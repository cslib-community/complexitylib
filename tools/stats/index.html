What is counted?

Tokei 12.1.2 counts code, comments, and blank lines in tracked .lean files. Each point is the last first-parent ancestor available by the end of that UTC day (today is partial); quiet days carry the previous snapshot. Dependencies, untracked files, and generated build outputs are excluded. Tracked generated Lean files, including import aggregates, are included.

The old Complexity/ and current CslibFrontier/ roots share a category. Historical abstracts and the current results registry are grouped together. File moves between categories can change individual series. Line counts measure source volume, not theorem count, correctness, or research progress.
