# Learning and property testing

The learning development makes a useful distinction between statistical/sample complexity, membership-query complexity and native running time. Its main local algorithms prove the first two. They should not be described as computational PAC learners merely because their sample or query bounds are polynomial or quasi-polynomial. [cslib-frontier][complexitylib]

## Upstream PAC and local uniform learning

Upstream [ConceptClass](https://github.com/leanprover/cslib/blob/254e30e6d4299c51323aaeaf5f51a4763b375d4a/Cslib/MachineLearning/PACLearning/Defs.lean#L121) defines a concept class as a set of functions and a learner as a function from an indexed labelled sample to a hypothesis. Success probabilities and excess error are measured over an explicit family of input/label distributions. It provides deterministic and internally randomized PAC notions and sample-complexity operators. The `R` in `IsRPACLearnerFor` denotes randomized, not realizable; realizability is imposed through the chosen distribution family. A learner is not required to be an encoded algorithm in this definition. [cslib][cslib]

Local [uniformExamples](https://github.com/cslib-community/cslib-frontier/blob/13e6a31951bf1c89a1a6258c44f9444aecbbefd8/Complexity/MachineLearning/UniformLearning/Basic.lean#L91) specializes to Boolean functions on a finite cube and independent uniform examples. `uniformError` is the fraction of cube inputs on which the hypothesis differs from the target. `Learns` bounds this error with failure probability delta after a prescribed number of labelled samples. Its bridge to upstream PAC instantiates the uniform realizable family; it does not establish distribution-free learning.

The [low-degree Fourier learner](https://github.com/cslib-community/cslib-frontier/blob/13e6a31951bf1c89a1a6258c44f9444aecbbefd8/Complexity/MachineLearning/UniformLearning/LowDegree.lean) estimates low-degree coefficients from examples and thresholds the resulting polynomial. With N retained coefficients, its sample condition is of the form `m >= (4N/epsilon) log(2N/delta)` together with a Fourier-tail assumption. The [AC0 learning theorem](https://github.com/cslib-community/cslib-frontier/blob/13e6a31951bf1c89a1a6258c44f9444aecbbefd8/Complexity/MachineLearning/UniformLearning/AC0.lean) combines this learner with Linial–Mansour–Nisan concentration, giving quasi-polynomial sample bounds for the stated bounded-depth/size circuit class. The local exponent is the implementation's quantitative version, with its circuit-depth convention; native Fourier arithmetic and hypothesis-evaluation time are not part of this theorem.

The upstream randomized variant, [IsRPACLearnerFor](https://github.com/leanprover/cslib/blob/254e30e6d4299c51323aaeaf5f51a4763b375d4a/Cslib/MachineLearning/PACLearning/Defs.lean#L181), chooses a sample-to-hypothesis learner using an internal probability space and bounds the expected sample-failure probability, with the stated almost-everywhere measurability condition. This is a separate semantic randomization layer from random training examples.

## Distribution-free realizable PAC learning

Realizable PAC learning over arbitrary distributions uses the upstream deterministic notion `IsPACLearnerFor` with the family [realizableDistributions](../../CslibFrontier/MachineLearning/PACLearning/Realizable.lean) of joint distributions on which some concept of the class has zero error. That module is a copy of the open CSLib pull request #858. [RealizableSample](../../CslibFrontier/MachineLearning/PACLearning/RealizableSample.lean) shows that i.i.d. samples from such a distribution are almost surely realizable. It follows that a learner which is consistent in the upstream `VersionSpace` sense almost surely outputs a concept agreeing with the whole sample. [ERM](../../CslibFrontier/MachineLearning/PACLearning/ERM.lean) defines empirical risk minimization through the upstream `empiricalMiscount` and proves that every ERM learner is consistent on realizable samples.

[FiniteClass](../../CslibFrontier/MachineLearning/PACLearning/FiniteClass.lean) proves the Occam bound for a finite class `H`, following Shalev-Shwartz and Ben-David, Corollary 2.3. Every consistent learner, in particular every ERM learner, fails to reach error `ε` with probability at most `|H| (1 - ε)^m`, hence at most `δ` once `log |H| + log (1/δ) ≤ ε m`. The corollaries give `IsPACLearnerFor` over `realizableDistributions H` and the sample-complexity bound `⌈(log |H| + log (1/δ))/ε⌉`. The probability statements assume that each hypothesis has a measurable misclassification set. `measurableSet_misclassified` supplies this when the hypotheses are measurable and the label type has measurable equality, for example `Bool`. The learners are semantic maps: no running time or hypothesis representation is claimed.

[GrowthFunction](../../CslibFrontier/MachineLearning/PACLearning/GrowthFunction.lean) defines `restriction`, the set of labelings a binary class induces on a sequence of `m` points, and the growth function, the maximum size of that set. It proves Sauer's lemma, `∑_{i ≤ d} (m choose i)`, for any class whose shattered finite sets have at most `d` points; the combinatorial core is Mathlib's Sauer–Shelah lemma for set families. It also proves the forms `(m + 1)^d` and `(e m / d)^d` for `d ≤ m`, and `2^m` on a shattered set. The general binomial bound `∑_{i ≤ d} (n choose i) ≤ (n + 1)^d` lives in [Foundations/Data/Nat/Choose/Sum](../../CslibFrontier/Foundations/Data/Nat/Choose/Sum.lean), which the low-degree Boolean analysis also uses. [PACLearning/VCDimension](../../CslibFrontier/MachineLearning/PACLearning/VCDimension.lean) adds two facts about the upstream `vcDim`: a shattered finite set has at most `vcDim C` points when `HasFiniteVCDim C` (`SetShatters.card_le_vcDim`), and every class on a finite domain has finite VC dimension (`hasFiniteVCDim_of_finite`).

[EpsilonNet](../../CslibFrontier/MachineLearning/PACLearning/EpsilonNet.lean) proves the ε-net theorem by double-sample symmetrization. The measure-theoretic steps are reusable and live in [DoubleSample](../../CslibFrontier/MachineLearning/PACLearning/DoubleSample.lean). `swapSamples σ` exchanges chosen coordinates between two samples and preserves `μ^m × μ^m` on any measurable space with σ-finite `μ` (`measurePreserving_swapSamples`). If at most `2^m K` of the `2^m` swaps of every double sample land in a measurable set `J`, then `J` has probability at most `K` (`measure_prod_le_of_card_filter_swapSamples_mem_le`). The ghost-sample bound `ν B ≤ 2 (ν × ν') J` holds when every `S ∈ B` extends into `J` with probability at least `1/2` (`measure_le_two_mul_measure_prod`). A sample is an ε-net for a class `G` under `μ` if it meets every `g ∈ G` of mass at least `ε` (`IsEpsNet`). For `εm ≥ 8`, `m` i.i.d. samples fail to be an ε-net with probability at most `2 Π_G(2m) / 2^⌈εm/2⌉` (`measure_pi_not_isEpsNet_mul_two_pow_le`). With Sauer's lemma, `vcSampleSize d ε δ = (8/ε)(d log (48/ε) + log (4/δ))` samples bring this below `δ` (`measure_pi_not_isEpsNet_le_of_vcSampleSize_le`). Here `d` bounds the size of every finite set shattered by the class; `hasFiniteVCDim_iff` supplies such a `d` from `HasFiniteVCDim`. [VCUpperBound](../../CslibFrontier/MachineLearning/PACLearning/VCUpperBound.lean) applies the theorem to the loss class of `C`. Every consistent learner, in particular every ERM learner, then reaches error `ε` with confidence `1 - δ` from `vcSampleSize d ε δ` examples over every distribution realizable by `C` (`IsConsistent.measure_pi_lt_error_le_of_vcSampleSize_le`). This is the VC upper bound of Blumer, Ehrenfeucht, Haussler and Warmuth (Theorem 2.1) with different constants of the same form. The corollaries are `isPACLearnerFor_realizableDistributions_of_vcSampleSize_le`, the realizable sample-complexity bound `⌈vcSampleSize (vcDim C) ε δ⌉` (`sampleComplexity_realizableDistributions_le_of_hasFiniteVCDim`), and `isPACLearnable_realizableDistributions_of_hasFiniteVCDim` for every class of finite VC dimension. These results assume a countable domain with measurable singletons and `Bool` labels, so that every set of samples is measurable. General domains need a measurability ("well-behaved") hypothesis on the class; issue #2868 tracks that case. The matching EHKV lower bound `Ω(d/ε)` is being developed upstream in CSLib.

Complete clients: [RealizablePAC.lean](../../CslibFrontierTests/RealizablePAC.lean) discharges the measurability side condition with `measurableSet_misclassified (measurable_of_countable _)`. It also checks the realizable and non-realizable distributions, ERM and non-consistent learners, Occam and VC sample-complexity bounds for small parameters, a tight Sauer bound for thresholds, and the swap-counting and ghost-sample bounds on one-point samples.

## Agnostic PAC learning

The upstream `IsPACLearnerFor` already measures success against `optimalError D C`, the best error in the class, so agnostic PAC learning is `IsPACLearnerFor` over the family `Set.univ` of all distributions; no realizability is assumed. [UniformConvergence](../../CslibFrontier/MachineLearning/PACLearning/UniformConvergence.lean) defines `IsRepresentative D C ε S`: the empirical error of every `h ∈ C` on `S` is within `ε` of its true error (Shalev-Shwartz and Ben-David, Definition 4.1). Hoeffding's inequality for one hypothesis (`measure_pi_le_abs_empiricalMiscount_div_sub_error`) and a union bound give uniform convergence for a finite class: `m` i.i.d. examples fail to be `ε`-representative with probability at most `|H| · 2 exp (-2 m ε²)` (`measure_pi_not_isRepresentative_le`). On an `ε / 2`-representative sample every empirical risk minimizer has error at most `optimalError D C + ε` (`IsRepresentative.error_le_optimalError_add`, Lemma 4.2, for any class). [AgnosticFiniteClass](../../CslibFrontier/MachineLearning/PACLearning/AgnosticFiniteClass.lean) combines them into Corollary 4.6. Under every distribution, an ERM learner for a finite class `H` misses `optimalError D H + ε` with probability at most `δ` once `2 log (2 |H| / δ) ≤ ε² m` (`IsERM.measure_pi_lt_error_le_of_log_le`). The corollaries are `isPACLearnerFor_univ_of_log_le`, the agnostic sample-complexity bound `⌈2 log (2 |H| / δ) / ε²⌉` (`sampleComplexity_univ_le_of_finite`) and `isPACLearnable_univ_of_finite`. The first two assume `[Nonempty (α → β)]`: for empty `H` the sample-size condition already holds at `m = 0`, and a learner from zero examples exists only if some hypothesis `α → β` does. The domain and labels are arbitrary measurable spaces; as in the realizable case, each hypothesis needs a measurable misclassification set, and the learners are semantic maps. The agnostic VC bound for infinite classes is tracked by issue #3005.

Complete client: [AgnosticPAC.lean](../../CslibFrontierTests/AgnosticPAC.lean) uses a distribution that labels one point both ways. No class realizes it, and the two constant hypotheses have optimal error `1 / 2` under it. The file checks a representative sample and a non-representative one. It also places the agnostic sample complexity of the constants at `(1/2, 1/2)` in `[1, 17]`.

## Rademacher complexity

[Rademacher/Basic](../../CslibFrontier/MachineLearning/Rademacher/Basic.lean) follows Mohri, Rostamizadeh and Talwalkar, Definitions 3.1 and 3.2. `rademacherAverage a` is `𝔼_σ ⨆ j, 𝔼 i, signVal (σ i) * a j i` for a family of vectors `a : ι → Fin m → ℝ`, with uniform bits turned into signs by `signVal`. `empiricalRademacherComplexity F S` is the Rademacher average of the restrictions of the functions `f ∈ F` to the sample `S : Fin m → Z`. `rademacherComplexity D F m` averages it over `Probability.PMF.pi` of `m` independent draws from `D : PMF Z` on a finite type `Z`, which is the setting of the finite McDiarmid inequality. The supremum is the real `⨆`, so results assume a class bounded on the sample. For a sign vector `σ` whose correlations are unbounded above, the supremum inside the expectation takes the junk value `0`; no theorem reaches that case. The definitions are not exposed: rewrite with `rademacherAverage_def`, `empiricalRademacherComplexity_def` and `rademacherComplexity_def`. Suprema over a bounded class need `BddAbove` side conditions, supplied by `Fintype.bddAbove_range_expect` and `Cslib.BitString.bddAbove_range_expect_signVal_mul`. Massart's lemma is `Cslib.BitString.expect_ciSup_sum_mul_signVal_le` in [BitString/Massart](../../CslibFrontier/Probability/BitString/Massart.lean): for `N` vectors of Euclidean norm at most `r`, the expected maximal signed sum is at most `r √(2 log N)` (Massart 2000, Lemma 5.2; MRT Theorem 3.7). Its proof uses the sign moment-generating bound `expect_exp_mul_sum_mul_signVal_le` of [BitString/Rademacher](../../CslibFrontier/Probability/BitString/Rademacher.lean) and Jensen's inequality. `rademacherAverage_le` and `rademacherAverage_le_mul_sqrt` are the normalized forms. For a class bounded by `B`, `empiricalRademacherComplexity_le_of_finite` bounds the empirical complexity by `B √(2 log P / m)`, where `P` is the number of distinct restrictions to the sample. That is MRT Corollary 3.8 for bounded real classes; the source states it for `{-1, +1}`-valued classes. The finite-class forms are `empiricalRademacherComplexity_le_of_finset` and `rademacherComplexity_le_of_finset`. A single function has complexity `0` (`empiricalRademacherComplexity_singleton`, `rademacherComplexity_singleton`), and the complexity is monotone in the class (`empiricalRademacherComplexity_mono`). Two bounded families realizing the same vectors have the same average (`rademacherAverage_eq_of_forall_exists`). `rademacherAverage_add_mul_signVal_mul` is affine invariance: translating every vector by a fixed `c`, flipping fixed coordinates and scaling by `β ≥ 0` multiplies the average by `β`.

[Rademacher/Generalization](../../CslibFrontier/MachineLearning/Rademacher/Generalization.lean) proves MRT Theorem 3.3 for classes with values in `[a, b]`, where the source has `[0, 1]`. Bartlett and Mendelson, Theorem 8, is a variant for loss classes with a different normalization of the Rademacher complexity and different constants. Symmetrization, `sum_pi_mul_ciSup_sub_le_two_mul_rademacherComplexity`, bounds the expected worst-case gap `𝔼_S sup_f (E_D f - Ê_S f)` by `2 R_m(F)` using a ghost sample and coordinate swaps. McDiarmid's inequality then applies through the closure lemmas `HasBoundedDifferences.ciSup` and `HasBoundedDifferences.expect` in [BoundedDifferences](../../CslibFrontier/Probability/BoundedDifferences.lean). They show that the worst-case gap and the empirical complexity (`hasBoundedDifferences_empiricalRademacherComplexity`) change by at most `(b - a) / m` when one sample point changes. `rademacherComplexity_generalization_bound` (MRT (3.3)) states that with probability at least `1 - δ` every `f ∈ F` has `E_D f ≤ Ê_S f + 2 R_m(F) + (b - a) √(log (1/δ) / (2m))`. `empiricalRademacherComplexity_generalization_bound` (MRT (3.4)) is the data-dependent form, with `2 R̂_S(F) + 3 (b - a) √(log (2/δ) / (2m))`. Both are stated as outer-measure bounds `≤ δ` on the failure event, for `m > 0`, `a < b` and `δ > 0`. `rademacher_generalization_bound_of_finset` combines (3.3) with Massart for a finite `[0, 1]`-valued class. It illustrates the method; Hoeffding's inequality with a union bound gives the sharper `√(log (|F|/δ) / (2m))`.

[Rademacher/GrowthFunction](../../CslibFrontier/MachineLearning/Rademacher/GrowthFunction.lean) handles binary classes. `signClass C` is the set of `{-1, +1}`-valued functions `signVal ∘ c` for `c ∈ C`. Its empirical complexity on `m` points is at most `√(2 log Π_C(m) / m)` (`empiricalRademacherComplexity_signClass_le`, MRT Corollary 3.8). With Sauer's lemma from [GrowthFunction](../../CslibFrontier/MachineLearning/PACLearning/GrowthFunction.lean) it is at most `√(2 d log (e m / d) / m)` for `d ≤ m` (`empiricalRademacherComplexity_signClass_le_vc`, with MRT Corollary 3.18), and at most `√(2 d log (m + 1) / m)` for all `m` (`empiricalRademacherComplexity_signClass_le_add_one`). Here `d` bounds every finite set shattered by `C`. The Rademacher-complexity forms are `rademacherComplexity_signClass_le` and `rademacherComplexity_signClass_le_vc`.

[Rademacher/Classification](../../CslibFrontier/MachineLearning/Rademacher/Classification.lean) gives the binary-classification bounds of MRT Section 3.1 to 3.3 on a finite domain `α`, for a distribution `D : PMF (α × Bool)` on labeled examples. The source states them for an arbitrary input space. The true error of `h` is `(D.toOuterMeasure {p | h p.1 ≠ p.2}).toReal` and its empirical error is `empiricalMiscount h S / m`. The bridges to the general theorems are `sum_mul_bitVal_decide_ne` and `expect_bitVal_decide_ne`. `bitClass C` is the set of `{0, 1}`-valued functions `bitVal ℝ ∘ c`, so `bitClass (lossClass C)` is the class of 0-1 losses `(x, y) ↦ 𝟙[h x ≠ y]`; `lossClass` and `mem_lossClass` live in [VCUpperBound](../../CslibFrontier/MachineLearning/PACLearning/VCUpperBound.lean). MRT Lemma 3.4 is `empiricalRademacherComplexity_bitClass_lossClass`: on a labeled sample the loss class has half the empirical complexity of `signClass C` on the unlabeled points. The proof writes `𝟙[a ≠ y] = 1/2 + (1/2) signVal (!y) signVal a` and applies affine invariance. Its expected form `rademacherComplexity_bitClass_lossClass` uses the marginal `D.map Prod.fst`. MRT Theorem 3.5 is `rademacherComplexity_classification_bound` for (3.17) and `empiricalRademacherComplexity_classification_bound` for (3.18). With probability at least `1 - δ`, every `h ∈ C` has `err_D(h) ≤ err_S(h) + R_m(signClass C) + √(log (1/δ) / (2m))`, or the data-dependent form with `R̂_{S_X}(signClass C) + 3 √(log (2/δ) / (2m))`. `growthFunction_classification_bound` is MRT Corollary 3.9, with `√(2 log Π_C(m) / m)`. `vc_classification_bound` is MRT Corollary 3.19, with `√(2 d log (e m / d) / m)`, for `m ≥ d`, which the source assumes implicitly through Corollary 3.18. For empirical risk minimization, `IsERM.rademacherComplexity_agnostic_bound` combines (3.17) at confidence `δ / 2` with Hoeffding's upper tail for a best concept at confidence `δ / 2`. The tail comes from the generalization bound for a singleton class, whose complexity is `0`. With probability at least `1 - δ`, an ERM output satisfies `err_D(A S) ≤ err_D(c) + R_m(signClass C) + √(2 log (2/δ) / m)` for every `c ∈ C`. `IsERM.vc_agnostic_bound` is the VC form, with excess error `√(2 d log (e m / d) / m) + √(2 log (2/δ) / m)`. These are derived results whose constants differ from SSBD Chapter 26. The countable-domain route through growth-function uniform convergence and `IsPACLearnerFor` packaging is #3005.

[Rademacher/Contraction](../../CslibFrontier/MachineLearning/Rademacher/Contraction.lean) proves Talagrand's contraction lemma in the uncentered form of [Mohri, Rostamizadeh and Talwalkar][mohrirostamizadehtalwalkar18], Section 5.4, Lemma 5.7 (cf. [Ledoux and Talagrand][ledouxtalagrand91], Theorem 4.12). For a uniformly bounded family `a : ι → Fin m → ℝ` and per-coordinate `K`-Lipschitz maps `φ i : ℝ → ℝ` (`K : ℝ≥0`), `rademacherAverage_comp_le` gives `rademacherAverage (fun j i => φ i (a j i)) ≤ K * rademacherAverage a` without requiring `φ i 0 = 0`, by coordinate-by-coordinate sign-flip symmetrization. The class forms bound empirical and population Rademacher complexities both for `(φ ∘ ·) '' F` (`empiricalRademacherComplexity_image_comp_le`, `rademacherComplexity_image_comp_le`) and for example-dependent Lipschitz losses `(fun f z => φ z (f (g z))) '' F` against `g ∘ S` and `D.map g` (`empiricalRademacherComplexity_image_comp_le_of_map`, `rademacherComplexity_image_comp_le_of_map`), as well as per-index compositions (`rademacherAverage_comp_le_empiricalRademacherComplexity`).

[Rademacher/Margin](../../CslibFrontier/MachineLearning/Rademacher/Margin.lean) formalizes the fixed-`ρ` margin bounds of [Mohri, Rostamizadeh and Talwalkar][mohrirostamizadehtalwalkar18], Section 5.4 (Definitions 5.5–5.6 and Theorem 5.8). `marginLoss ρ u = min 1 (max 0 (1 - u / ρ))` takes values in `[0, 1]` (`marginLoss_mem_Icc`), sandwiches `𝟙[u ≤ 0] ≤ marginLoss ρ u ≤ 𝟙[u ≤ ρ]` for `ρ > 0` (`boole_le_marginLoss`, `marginLoss_le_boole`), and is `(1 / ρ)`-Lipschitz (`lipschitzWith_marginLoss`, `lipschitzWith_marginLoss_nnreal`). For a distribution `D : PMF (α × Bool)` on a finite domain `α` (reading labels via `signVal y ∈ {-1, +1}`) and a uniformly bounded real hypothesis class `H : Set (α → ℝ)`, `empiricalMarginLoss` and `marginRisk` define the empirical and population `ρ`-margin losses, `marginLossClass ρ H` contracts by `1 / ρ`, and `rademacherComplexity_margin_bound` (MRT (5.39)) and `empiricalRademacherComplexity_margin_bound` (MRT (5.40)) bound the event that some `h ∈ H` exceeds `empiricalMarginLoss ρ h S + (2 / ρ) R_m(H) + √(log (1/δ) / (2m))` (resp. `(2 / ρ) R̂_{S_X}(H) + 3 √(log (2/δ) / (2m))`) in true error `(D.toOuterMeasure {p | signVal p.2 * h p.1 ≤ 0}).toReal` by `δ`. `margin_bound_of_finset` specializes (5.39) to finite classes via Massart's lemma. Margin bounds uniform in `ρ` (MRT Theorem 5.9), local Rademacher complexity and measurable (non-finite) domains remain open ([#3297](https://github.com/cslib-community/cslib-frontier/issues/3297)).

Complete clients: [RademacherComplexity.lean](../../CslibFrontierTests/RademacherComplexity.lean) computes complexity `0` for a single function and an empty sample. On a one-point sample, the two constant functions `±1` have empirical complexity exactly `1`, which Massart bounds by `√(2 log 2)`. It instantiates the finite-class bound with `m = 100` and `δ = 1/20` at a gap of `61/100`, the data-dependent bound (3.4) with `m = 10000` and `δ = 1/20` at a gap of `1/5`, and the VC bounds with `d = 2` on `Bool`, including `R̂_S ≤ 1/2` on `100` points. For classification, the 0-1 losses of the two constant classifiers on one labeled point have complexity exactly `1/2`, a single classifier gives Hoeffding's tail, and with `m = 65536` and `δ = 1/20` the VC bound gives a gap of `0.06` and ERM over all classifiers on `Bool` is within `0.08` of a Bayes-optimal one. [RademacherMargin.lean](../../CslibFrontierTests/RademacherMargin.lean) checks an exact equality case (`u ↦ 5 - 3u` on `{±1}`, attaining `3`) and a strict collapse case (`abs`) of Talagrand contraction, boundary and interior values of `marginLoss (1/2)` and `empiricalMarginLoss`, and nonvacuous `m = 10000`, `ρ = 1/2`, `δ = 1/20` instances of both `margin_bound_of_finset` (gap `0.12`) and `empiricalRademacherComplexity_margin_bound` (gap `0.23`).

## Membership-query learners

[QueryLearner](https://github.com/cslib-community/cslib-frontier/blob/13e6a31951bf1c89a1a6258c44f9444aecbbefd8/Complexity/MachineLearning/UniformLearning/MembershipQuery.lean#L76) takes a random seed to a decision tree. A queried coordinate is itself an input point for the unknown target function, and a leaf is a hypothesis function. `QueriesAtMost` bounds tree depth for every seed. This represents adaptive membership queries directly, while nonadaptive point lists are a specialization.

Uniform random examples can be simulated by querying independently sampled points, with exact distributional correctness. The [Kushilevitz–Mansour development](https://github.com/cslib-community/cslib-frontier/blob/13e6a31951bf1c89a1a6258c44f9444aecbbefd8/Complexity/MachineLearning/UniformLearning/KushilevitzMansour.lean) reuses a nonadaptive sample set across stages, with the explicit query bound `m(2n+3)` and a sample schedule depending on spectral norm, error and confidence. Bounded-leaf decision trees supply a concrete learnable class through a spectral-norm bound. These statements charge oracle queries only; they do not bound the time or finite representation needed for all Fourier operations and output hypotheses.

The [Nisan–Wigderson learner](../../CslibFrontier/MachineLearning/UniformLearning/NisanWigderson.lean) runs the reconstruction of the Nisan–Wigderson generator as a non-adaptive membership-query learner, following Carmosino, Impagliazzo, Kabanets and Kolokolova. [carmosinoimpagliazzokabanetskolokolova2016][carmosinoimpagliazzokabanetskolokolova2016] `nwLearner D test` takes a design `D` and a test on `m`-bit strings; its seeds are the trials of the [sampled reconstruction](../../CslibFrontier/Crypto/Primitives/PRG/NisanWigderson/Sampling.lean). On a trial it queries the at most `m 2^a` points of [`trialPoints`](../../CslibFrontier/Crypto/Primitives/PRG/NisanWigderson/Queries.lean) (`nwLearner_queriesAtMost`) and outputs the trial's guess (`eval_nwLearner`), which `trialGuess_congr` shows reads the target only there. Every hypothesis has De Morgan circuit size at most that of the test plus `m (2^a (2a + 3) + 1) + 1` (`complexity_eval_nwLearner_le`). `nwLearner_learns` turns a distinguisher with advantage `ε` against the generator of every target in `C` into learning with error `1/2 - ε/(2m)` and success probability `ε/(2m)`, and `nwLearner_learns_of_dens` takes a test accepting a `δ` fraction of all strings but no generator output, the natural-property form, through its negation. `QueryLearner.learns_uniformOfFintype_of_le_dens` is the bridge: with uniform seeds from a finite type, a density lower bound on the good seeds gives `Learns`, and `uniformError_eq_one_sub_dens` writes the error as one minus the agreement density. This is one run of their Theorem 2.11 with `δ` in place of `1/5` and advantage `δ/(2m)` in place of `1/L`. [Selecting the best of `k` runs](../../CslibFrontier/MachineLearning/UniformLearning/NisanWigderson/BestOf.lean) gives Theorem 2.11 in a library form: `bestOf_nwLearner_learns` turns a distinguisher with advantage `ε > 0` against the generator of every target in `C` into learning `C` with error `1/2 - ε/(4m)` and confidence `1 - η` when `ε/(2m) ≤ 1`, `log (2/η) ≤ (ε/(2m)) k` and `8 log (4k/η) ≤ t (ε/(2m))²`, and `bestOf_nwLearner_learns_of_dens` is its natural-property case with `δ` in place of `ε`. The learner makes at most `k m 2^a + t` queries (`bestOf_nwLearner_queriesAtMost`) and keeps the single-run circuit bound (`complexity_eval_bestOf_nwLearner_le`); the source takes advantage above `1/5`, has error `1/2 - 1/L` and uses `poly(L)` runs. Complete client: [NisanWigdersonBestOf.lean](../../CslibFrontierTests/NisanWigdersonBestOf.lean) uses `8` runs and `1000` sample points for error `1/2 - 3/32` with confidence `1/2`. Only queries and hypothesis size are certified, not the running time.

[Best-of-`k` selection](../../CslibFrontier/MachineLearning/UniformLearning/BestOf.lean) turns a learner that succeeds with small probability into one with confidence `1 - η`. `bestOf A k t` runs `A` on `k` independent seeds, queries the target at `t` fresh uniform points and outputs a hypothesis with the most agreements there; `bestOfSeed μ k t` is its seed distribution. It makes at most `k * q + t` queries when every run makes at most `q` (`queriesAtMost_bestOf`), and it outputs the hypothesis of one of the runs (`exists_eval_bestOf_eq`), so any complexity bound on the runs' hypotheses carries over (`le_sup_eval_bestOf`). `learns_bestOf` turns error `ε` with confidence `1 - δ` into error `ε + 2θ` with confidence `1 - δ ^ k - 2k exp (-2tθ²)`, by Hoeffding's inequality and a union bound over the runs. `learns_bestOf_of_success` solves for the parameters: error `ε` with probability `p` becomes error `ε + 2θ` with confidence `1 - η` when `log (2/η) ≤ p k` and `log (4k/η) ≤ 2tθ²`. `learns_bestOf_of_weak`, its case `θ = γ/4`, is the weak-learner form used by Carmosino, Impagliazzo, Kabanets and Kolokolova (CCC 2016, Theorem 2.11): agreement `1/2 + γ` with probability `p` becomes agreement `1/2 + γ/2` with probability `1 - η` when `log (2/η) ≤ p k` and `8 log (4k/η) ≤ t γ²`. Only queries are certified, not running time. The Nisan–Wigderson instance of Theorem 2.11 is above. Complete client: [QueryLearnerBestOf.lean](../../CslibFrontierTests/QueryLearnerBestOf.lean) boosts a learner that outputs the target's negation half of the time, with `6` runs and `1504` sample points, to error `1/4` with confidence `1/2`.

[The parameters of the CIKK learner](../../CslibFrontier/MachineLearning/UniformLearning/CIKK/Parameters.lean) fix, as explicit numerals in exponents `e`, `g` and `h` (error `2^{-e}`, advantage `2^{-g}`, confidence `1 - 2^{-h}`), the direct-product length `cikkK e g`, a power of two, the Goldreich–Levin mask count `cikkMasks`, the decoder's fixed-set size `cikkFixed` and trial count `cikkTrials`, and the runs `cikkRuns` and sample points `cikkSamples` of best-of selection. Their lemmas discharge, in the forms the stages take and after `log x ≤ N` for `0 < x ≤ 2^N` (`Real.log_le_of_le_two_pow`), the Goldreich–Levin list condition and the direct-product conditions of Carmosino, Impagliazzo, Kabanets and Kolokolova's Theorem 5.1, and the conditions of one outer best-of selection. That outer selection is the library's: the source composes the Nisan–Wigderson and amplification reconstructions, each boosting its own confidence (proof of Theorem 3.2, p. 10:11), and one final boost replaces them at the cost of constants. Taking `k` a power of two solves the fixed point `2s ≤ k` (`two_mul_cikkFixed_le_cikkK`) in place of the source's `k = ⌈3c/ε · ln(1/γ)⌉ + 1` (proof of Theorem 4.3, step 1, p. 10:15), and `k ≤ 2^{e+10} (6g + 3e + 36)` (`cikkK_le`). The closed forms `cikkLogK_le`, `cikkK_le_two_pow`, `cikkMasks_le`, `cikkFixed_le`, `cikkTrials_le`, `cikkRuns_le` and `cikkSamples_le` bound every parameter by a power of two with exponent linear in `e`, `g` and `h`, so bounds on the learner need not unfold the definitions. Complete client: [CIKKParameters.lean](../../CslibFrontierTests/CIKKParameters.lean) boosts a learner with the amplification stage's success probability through `learns_bestOf_of_success`.

[Black-box reductions](../../CslibFrontier/MachineLearning/UniformLearning/Reduction.lean) learn a class `C` from a learner `A` for a transformed class `amp '' C`. `reduce A s post` runs `A`, answers each query `amp f y` with a decision tree `s y` that queries `f` (`DecisionTree.substitute`), and post-processes the hypothesis of `A` with an extra seed. Run on `f`, it outputs the post-processed hypothesis of `A` run on `amp f` (`eval_reduce`). It makes at most `q * d` queries when `A` makes at most `q` and every `s y` has depth at most `d` (`queriesAtMost_reduce`). `learns_reduce` multiplies success probabilities: suppose `A` succeeds with probability `p` and, for every `f ∈ C`, post-processing turns every hypothesis with error `ε'` against `amp f` into one with error `ε` against `f` for a `ρ` fraction of the extra seeds. Then the reduction, run on `reduceSeed μ T`, succeeds with probability `p * ρ`. This is the reconstruction property of black-box amplification (Carmosino, Impagliazzo, Kabanets and Kolokolova, CCC 2016, Definition 3.4), with the oracle given by the trees `s y`. Only queries are certified, not running time. Complete client: [AmpReconstruction.lean](../../CslibFrontierTests/AmpReconstruction.lean) runs the trivial reduction, which asks each query directly.

The [reconstruction for `Amp(f) = (f^k)^GL`](../../CslibFrontier/MachineLearning/UniformLearning/CIKK/Amplification.lean) is a black-box reduction (Carmosino, Impagliazzo, Kabanets and Kolokolova, Theorem 4.3). `ampLearner A s m K` answers each query of `A` to `glAmp f k` with the `k` queries of `glAmpQuery`, so it makes at most `q * k` queries (`queriesAtMost_ampLearner`). It decodes the hypothesis of `A` first with the Goldreich–Levin candidate `glAmpCandidate` for `K` masks and a parity guess, then with the direct-product decoder `dpDecode`; its seed distribution is `ampSeed μ k s m K`. `learns_ampLearner` is the reconstruction in a library form (registry ID `cikk-amp-reconstruction`). If `A` learns `{glAmp f k | f ∈ C}` with error `1/2 - γ` and success probability `p`, then `ampLearner A s m K` learns `C` with error `ε` and success probability `p δ₀²/8`, where `δ₀ = γ/2^(K+3)`. The factor `δ₀²/8` is a `δ₀` fraction of good Goldreich–Levin seeds times a `δ₀/8` fraction of good direct-product seeds for each of them, combined by the two-stage sampling bound [`mul_le_dens_filter_prod`](../../CslibFrontier/Foundations/Probability/TwoStage.lean). It needs four conditions: `k ≤ 2(γ/2)²(2^K - 1)`, `2s ≤ k`, `s ≥ (64/ε) log(512/(ε δ₀²))` and `m ≥ (16/δ₀) log(8/ε)`. The module docstring labels where this departs from the source: the Goldreich–Levin list has `2^K = O(k/γ²)` entries instead of `O(1/γ²)`, each seed gives a deterministic decoder, the success probability and the constants are ours, and the parameter conditions are hypotheses rather than a choice of `k`. If the hypothesis of `A` has a De Morgan circuit with `c` gates, the reconstructed hypothesis has one with at most `m (s + 1) ((2^K - 1)(c + 1) + 8 + 2(2^K - 1)(2^K + 1)) + 3m + 1` (`complexity_eval_ampLearner_le` in [CIKK/Complexity.lean](../../CslibFrontier/MachineLearning/UniformLearning/CIKK/Complexity.lean)); running time is not certified. The [checked examples](../../CslibFrontierTests/CIKKAmplification.lean) evaluate `glAmpQuery` and state the reconstruction for a single function.

[The CIKK learner](../../CslibFrontier/MachineLearning/UniformLearning/CIKK/Learner.lean) composes the three stages at these parameters, for `p = 2` (Carmosino, Impagliazzo, Kabanets and Kolokolova, Theorem 5.1, in a per-function black-box form). `cikkLearner n ℓ e g h test` is best-of selection over the reconstruction for `Amp(f) = glAmp f (cikkK e g)` of the Nisan–Wigderson learner built from the negated test, for the design `Design.binaryPolynomial (k n + k) ℓ`; its seed distribution is `cikkSeed n ℓ e g h`. `learns_cikkLearner` is the learning theorem (registry ID `cikk-learning-from-dense-test`). Let the test, on strings of `2^ℓ` bits, accept at least `2^{2^ℓ} 2^{ℓ+1-g}` of them and no output of the generator of `glAmp f k` for any `f ∈ C`. Then the learner learns `C` with error `2^{-e}` and confidence `1 - 2^{-h}`. It makes at most `(h + 1) 2^{2ℓ + 10g + 6e + 59}` queries (`queriesAtMost_cikkLearner_two_pow`; exact count `queriesAtMost_cikkLearner`). The single outer best-of selection replaces the source's per-stage boosts, at the cost of constants. The test may have any density, not only the largeness `1/5` of a natural property, and the deviations of `learns_ampLearner` carry over; the module docstring labels them. Running time is not certified. Complete client: [CIKKLearner.lean](../../CslibFrontierTests/CIKKLearner.lean) specializes the theorem to one target and evaluates the query bound at small parameters. For AC⁰[2], [CIKK/AC0Mod.lean](../../CslibFrontier/MachineLearning/UniformLearning/CIKK/AC0Mod.lean) instantiates the test with the rank property (`learns_cikkLearner_rankTest`, registry ID `cikk-learning-ac0-2`), giving quasi-polynomially many queries and hypotheses of quasi-polynomial De Morgan circuit size for fixed target depth `d` (`complexity_eval_cikkLearner_rankTest_le_two_pow`; only size is certified, not depth); see [natural proofs](metacomplexity-and-methods.md#natural-proofs-and-cryptographic-assumptions).

[The size of the CIKK learner's hypotheses](../../CslibFrontier/MachineLearning/UniformLearning/CIKK/Complexity.lean) is bounded relative to the test (registry ID `cikk-learner-hypothesis-size`). On every target and seed, `complexity_eval_cikkLearner_le` bounds the hypothesis's De Morgan circuit size by `T (F + 1) ((2^K - 1)(c + N + 3) + 8 + 2(2^K - 1)(2^K + 1)) + 3T + 1`, where `c` is the test's circuit size, `N = 2^ℓ (2^{ℓ-1} (2(ℓ-1) + 3) + 1)` is the Nisan–Wigderson overhead, and `T`, `F` and `K` are `cikkTrials`, `cikkFixed` and `cikkMasks`. The closed form `complexity_eval_cikkLearner_le_two_pow` is `2^{11g + 9e + 3ℓ + 80} (c + 1)`, with this library's constants. The proof follows the output of `bestOf` to one run (`le_sup_eval_bestOf`), unfolds the learner with `cikkLearner_def`, and composes the bounds of the Nisan–Wigderson hypothesis, the Goldreich–Levin candidate and the direct-product decoder. The bound is affine in `c`, with `T (F + 1)(2^K - 1)` copies of the test. With unit-cost test gates it is the size that the source's oracle circuit would have, but that oracle circuit is not built. Only size is certified, not depth or running time. Complete client: [CIKKComplexity.lean](../../CslibFrontierTests/CIKKComplexity.lean) applies the closed form to a test of bounded size and composes one run's bounds.

## Statistical queries

The [statistical query model](../../CslibFrontier/MachineLearning/StatisticalQuery/Basic.lean) follows Kearns's Definition 3 on a finite domain `X` with a fixed distribution `D : PMF X`. A `Query X` is a function `X → Bool → ℝ` with values in `[-1, 1]`, so Kearns's `{0, 1}` predicates and Reyzin's `±1` queries are special cases. A learner is a deterministic `OracleComp (spec X) (X → Bool)` program whose calls are queries answered by reals. `OracleComp.IsQueryBounded` bounds its query count. `Learns A D C τ ε` requires error at most `ε` for every target in `C` and every answer sequence within `τ` of the true expectations, including adaptive answers (`OracleComp.supportWith`). `LearnsStateless` only quantifies over fixed answer functions. It is the weaker notion (`Learns.learnsStateless`), so lower bounds are stated for it. There is a single tolerance and no confidence parameter. A learner whose per-query tolerances are all at least `τ` is covered by the single tolerance `τ`.

The [lower bounds](../../CslibFrontier/MachineLearning/StatisticalQuery/LowerBound.lean) use Szörényi's argument as presented by Reyzin. `LearnsStateless.card_le_of_abs_corr_le` takes concepts `f i ∈ C` with pairwise `|corr D (f i) (f j)| ≤ γ`, a learner using at most `q` queries, `γ < τ²` and `γ < (1 - 2ε)²`. It bounds the number of concepts by `q (1-γ)/(τ²-γ) + (1-γ)/((1-2ε)²-γ)`. `card_le_of_corr_le` assumes only a one-sided correlation bound and doubles the first term. With `γ = 1/d`, so that the one-sided statistical query dimension is at least `d`, `card_mul_sq_sub_one_le_two_mul_add_one` takes Reyzin's Theorem 12 hypothesis of accuracy `τ` (`1 - 2ε ≥ τ`) and gives `d τ² - 1 ≤ 2q + 1`. Its exact-learning special case `ε = 0`, `card_mul_sq_sub_one_le_two_mul`, gives Reyzin's query count `d τ² - 1 ≤ 2q`. The [parity corollary](../../CslibFrontier/MachineLearning/StatisticalQuery/Parity.lean) `LearnsStateless.two_pow_card_le_of_parityOn_mem` gives `2^n ≤ q/τ² + 1/(1-2ε)²` for any class containing all parities on `n` bits under the uniform distribution. [CslibFrontierTests/StatisticalQuery.lean](../../CslibFrontierTests/StatisticalQuery.lean) has a concrete one-query learner, an edge case where tolerance `1` fails, and parity instances.

The [simulation](../../CslibFrontier/MachineLearning/StatisticalQuery/Simulation.lean) runs a learner on random examples in the block form of Reyzin's Section 2.1. `simulate n blocks A` answers the `i`-th call `φ` by the empirical mean `empirical φ (blocks i)` of `φ` on the `i`-th block of `m` labelled examples. `toOuterMeasure_simulate_notMem_le` is the union bound along an adaptive run: each call is answered from a block independent of the earlier ones, whatever the earlier answers were. It applies to any program with a query budget, any per-query set of acceptable answers and a uniform per-query failure bound `β`, giving `n β` for `n` queries. Hoeffding's inequality for an empirical average under an arbitrary finite distribution (`PMF.pi_abs_sum_div_sub_sum_mul_ge_le` in [Concentration](../../CslibFrontier/Probability/Concentration.lean)) gives `toOuterMeasure_empirical_notMem_valid_le`. Together they give `Learns.toOuterMeasure_lt_disagreement_simulate_le`: a learner with tolerance `τ ≥ 0`, error `ε` and at most `q` queries, run on `q` independent blocks of `m` examples of a target in `C`, has error above `ε` with probability at most `2 q exp(-m τ² / 2)`. `Learns.isPACLearnerFor` packages the learner `simulateLearner A q m` on `q m` examples, split into blocks along `finProdFinEquiv` (`PMF.pi_map_finProdFinEquiv` in [Product/Reindex](../../CslibFrontier/Probability/Product/Reindex.lean)). It is an `IsPACLearnerFor (q * m) ε δ C (realizable D C)` witness whenever `2 q exp(-m τ² / 2) ≤ δ`. This condition needs a positive tolerance. For `τ > 0` it holds once `m ≥ 2 log(2q/δ) / τ²`. At `τ = 0` it reads `2 q ≤ δ < 1`, so it applies only to learners making no queries. `realizable D C` contains the distributions of a `D`-random point labelled by a concept of `C`, so this is fixed-distribution PAC learning. Under the uniform distribution it is `UniformLearning.uniformRealizable C` by definition.

The [low-degree algorithm](../../CslibFrontier/MachineLearning/StatisticalQuery/LowDegree.lean) `lowDegree ι t` is a non-adaptive learner. Through `askAll` it asks `charQuery S`, `(x, y) ↦ signVal y · χ_S(x)`, for each of the `N` sets `S` of at most `t` coordinates, so it makes `N` queries (`isQueryBounded_lowDegree`), and returns the sign of `∑ c_S χ_S` for the answers `c_S`. Under the uniform distribution, `expect` of `charQuery S` is the Fourier coefficient on `S`, and `disagreement` is `UniformLearning.uniformError`. `learns_lowDegree` gives error `N τ² + κ` for every class whose Fourier weight above degree `t` is at most `κ`. `learns_lowDegree_parityOn` gives error `N τ²` for the parities on at most `t` coordinates, in contrast to the lower bound for all parities. [CslibFrontierTests/StatisticalQuerySimulation.lean](../../CslibFrontierTests/StatisticalQuerySimulation.lean) runs the one-query learner on two concrete blocks, giving different hypotheses. It checks a 40-example PAC instance and the low-degree learner on three bits, including the PAC learner it yields.

The [statistical query dimension](../../CslibFrontier/MachineLearning/StatisticalQuery/Dimension.lean) `sqDim D C` is Reyzin's Definition 11 for a fixed distribution: the largest `d` such that `C` contains `d` distinct concepts with pairwise `|corr D f g| ≤ 1/d`. Blum, Furst, Jackson, Kearns, Mansour and Rudich (BFJKMR) use the threshold `1/d³` in their Definition 2. Their dimension `d₃` and `d₁ = sqDim` satisfy `d₃ ≤ d₁ < (d₃+1)³`, so polynomial boundedness does not depend on the normalization; this relation is not formalized. The variant `sqDimOneSided D C` drops the absolute value and asks only `corr D f g ≤ 1/d`. This is the hypothesis Szörényi's lower-bound argument uses. `sqDim_le_sqDimOneSided` and `sqDimOneSided_le` give `sqDim ≤ sqDimOneSided ≤ 18 (sqDim + 1)³`, so the two are polynomially related. On the identity and negation of a bit, which have correlation `-1`, they are `1` and `2`. The dimension characterizes weak learning (Section 5 of BFJKMR). `LearnsStateless.sqDimOneSided_mul_sq_le` gives the lower bound `sqDimOneSided D C · τ² ≤ 2q + 2` when `1 - 2ε ≥ τ`, and hence `LearnsStateless.sqDim_mul_sq_le`. This is one weaker than Reyzin's Theorem 12 count `dτ² ≤ 2q + 1`, because a hypothesis with error `ε > 0` may correlate with one more concept. The exact-learning case is `card_mul_sq_sub_one_le_two_mul`. For the upper bound, `exists_cover_sqDim` takes a largest family `G ⊆ C` whose pairwise correlations have absolute value at most `1/(d+1)`, where `d = sqDim D C`. Then `|G| ≤ d`, and every concept of `C` has correlation of absolute value more than `1/(d+1)` with a member of `G`. Reyzin's Observation 23 sketch uses the family at threshold `1/d`; we choose the family at threshold `1/(d+1)`. The deterministic `corrLearner` asks the correlational query `corrQuery g` (`E_D[±g(x) · ±y]`) for each member of `G`. It takes the member whose answer has the largest absolute value and returns it, or its negation if that answer is negative, so its hypothesis need not lie in `C`. So `exists_learns_sqDim` (Reyzin's Observation 23, the analogue of BFJKMR's Theorem 13) makes at most `d` correlational queries and has error `1/2 - 1/(2(d+1)) + τ` against adaptive answers of every tolerance `τ`. Asymptotically, `tfae_polynomiallyBounded_sqDim` shows that four conditions are equivalent: a polynomially bounded `sqDim`, a polynomially bounded `sqDimOneSided`, weak learnability with polynomially many correlational queries of tolerance `1/(p n+1)` and advantage `1/(p n+1)` against adaptive answers, and the same with arbitrary queries against fixed answers. [CslibFrontierTests/StatisticalQueryDimension.lean](../../CslibFrontierTests/StatisticalQueryDimension.lean) computes the dimensions of small classes, separates `sqDim` from `sqDimOneSided`, runs the weak learner on the identity and negation of a bit, and derives that parities are not weakly SQ-learnable from `2^n ≤ sqDim`.

These are information-theoretic bounds on query count, tolerance and sample size. They do not charge running time, and the learners are deterministic. Simulation under random classification noise (Kearns's Lemma 2 and Theorem 3), the single-sample form of Kearns's Theorem 1 (with its finite-query-space and finite-VC-dimension sample bounds), and a distribution-free form are not yet formalized.

## Online learning with experts

The [multiplicative-update core](../../CslibFrontier/MachineLearning/OnlineLearning/MultiplicativeUpdate.lean) fixes the experts-setting conventions. Experts form a finite type, losses are an arbitrary real sequence `ℓ : ℕ → ι → ℝ`, and an update factor `φ` gives expert `i` the weight `∏ s < t, φ (ℓ s i)`; the learner plays `prob φ ℓ t`, the normalized weights, and pays `∑ i, prob φ ℓ t i * ℓ t i`. The distribution in round `t` depends only on earlier losses (`prob_congr`), and `adaptiveLoss_eq` shows the bounds cover adversaries that see the current distribution. Every analysis passes through the single potential inequality `sum_log_le_log_card_add`.

[Multiplicative weights](../../CslibFrontier/MachineLearning/OnlineLearning/MultiplicativeWeights.lean) (`mwFactor η x = 1 - η x`) has the Arora–Hazan–Kale regret bound `mw_regret_le` with its exact constants, the mixed-strategy form, a second-order variant and the tuned `2 √(T ln n)` bound. [Hedge](../../CslibFrontier/MachineLearning/OnlineLearning/Hedge.lean) (`exp (-η x)`) has the bound with the learner's expected squared loss and its tuned `2 √(T ln n)` form. [Weighted majority](../../CslibFrontier/MachineLearning/OnlineLearning/WeightedMajority.lean) proves `M(T) ≤ 2 (1 + η) mᵢ(T) + 2 ln n / η` for every tie-breaking rule, stated as a hypothesis on the predictions; the concrete rule `weightedMajority` satisfies it.

The hypotheses decide which statement applies. Multiplicative weights needs `0 < η ≤ 1 / 2` and losses in `[-1, 1]` (the second-order variant needs only `η ℓ ≤ 1 / 2`), and its tuned bound needs `n ≥ 2` and `T ≥ 4 ln n`. Hedge needs `0 < η ≤ 1` and losses in `[-1, 1]` (or only `η ℓ ≥ -1`), and its tuned bound needs `n ≥ 2` and `T ≥ ln n`. Weighted majority needs `0 < η ≤ 1 / 2`. The Blum–Mansour learner below needs the same `η` and losses as Hedge, and its tuned bound needs `n ≥ 2` and `T ≥ n ln n`. The zero-sum theorems need entries in `[0, 1]`, `0 < ε ≤ 1`, `T > 0` with `ε ^ 2 T ≥ 4 ln n`, and columns that best respond to the learner's distribution in every round. The declarations live in the namespace `Cslib.MachineLearning.OnlineLearning.Experts`.

[Zero-sum games](../../CslibFrontier/MachineLearning/OnlineLearning/ZeroSum.lean) run multiplicative weights on the rows against best-responding columns. After `T ≥ 4 ln n / ε ^ 2` rounds, the average row distribution and the empirical column distribution are `ε`-optimal, and the average payoff lies in `[v, v + ε]`. The value `v` is [IsMinimaxValue](../../CslibFrontier/Probability/Minimax/Value.lean), whose existence comes from the exact Sion-based minimax theorem in `Probability/Minimax`; `sum_averageProb_mul_le_add_of_forall_exists_sum_le` is the explicit `ε`-approximate counterpart of that theorem. The best-response property is a hypothesis, so any oracle can be used; `bestResponsePlay` (defined by choice) shows it is satisfiable. [Checked examples](../../CslibFrontierTests/OnlineLearning.lean) compute distributions, solve matching pennies, and show the mistake bound failing without the weighted-majority hypothesis.

[Swap regret](../../CslibFrontier/MachineLearning/OnlineLearning/SwapRegret.lean) compares the learner with every *swapping function* `δ : ι → ι`, which replaces each play of `i` by `δ i`: the learner has swap regret at most `R` if `∑ t, ∑ i, p t i * ℓ t i ≤ ∑ t, ∑ i, p t i * ℓ t (δ i) + R` for every `δ`. Constant `δ` gives external regret, the benchmark above; swap regret is strictly stronger. `swap_regret_le_sum_regret` is the Blum–Mansour reduction ([blummansour07][blummansour07], Theorem 5; [roughgarden13cs364a][roughgarden13cs364a], Lecture #18, Theorem 2.1). It runs one external-regret algorithm per action; row `j` of the matrix `q t` is copy `j`'s distribution. The learner plays a stationary vector `p t ᵥ* q t = p t`, and copy `j` sees the losses `p t j * ℓ t`. If copy `j` has regret at most `R j` against every action, the learner has swap regret at most `∑ j, R j`. The theorem takes stationarity and the copies' regret bounds as hypotheses, so any external-regret algorithm can be plugged in. Stationary vectors exist by [`Matrix.exists_vecMul_eq_self_of_mem_rowStochastic`](../../CslibFrontier/Foundations/LinearAlgebra/Matrix/Stochastic.lean): every real row-stochastic matrix over a finite nonempty type has one, and `Matrix.stationaryVec` chooses one. `blumMansourProb η ℓ` instantiates the reduction with Hedge copies (`blumMansourWeight`, with `blumMansourWeight_eq_weight` identifying copy `j` with Hedge on `blumMansourLoss η ℓ j`). It is online (`blumMansourProb_congr`), and `blumMansour_swap_regret_le` bounds its swap regret by `η T + n ln n / η`, because the copies' second-order Hedge terms sum to at most `η T`. `blumMansour_swap_regret_le_sqrt` takes `η = √(n ln n / T)` and gives `2 √(T n ln n)`, the order of Blum and Mansour's Corollary 7. [Checked examples](../../CslibFrontierTests/SwapRegret.lean) give a play sequence with zero external regret and swap regret `3`, compute a stationary vector, and show that the learner plays the uniform distribution against zero losses. The game-theoretic consequence, that no-swap-regret dynamics converge to approximate correlated equilibria (Blum and Mansour's Theorem 3), is not yet formalized; [#4201](https://github.com/cslib-community/cslib-frontier/issues/4201) tracks it.

All of these are real-valued statements about the defined update rules. They do not charge arithmetic, sampling or oracle calls, the Blum–Mansour learner's stationary vectors are chosen classically rather than computed, and randomized weighted majority is not yet modelled as a probabilistic computation.

## Online learning in the mistake-bound model

The [mistake-bound core](../../CslibFrontier/MachineLearning/OnlineLearning/MistakeBound/Basic.lean) formalizes Littlestone's realizable model. A deterministic `OnlineLearner α` predicts a `Bool` label from the labelled history and the current instance. `mistakes A S` counts its wrong predictions on a finite labelled sequence `S`. `Realizable C S` asks that some concept of the upstream `ConceptClass` agree with all of `S`. `mistakeBound A C : ℕ∞` is the supremum of the mistakes over realizable sequences, and `optimalMistakeBound C` is the infimum over learners. `mistakeBound_eq_iSup_adversary` shows that adaptive adversaries choosing instances and labels from the history add nothing for deterministic learners, and `mistakeBound_eq_iSup_concept` gives Littlestone's form with a fixed target. This model has no experts and no real-valued losses: the learner pays for each mistake against the realizability requirement. The non-realizable extension, with randomized learners and regret against the best concept, is described below under randomized learners and agnostic online learning.

[Mistake trees](../../CslibFrontier/MachineLearning/OnlineLearning/MistakeBound/Littlestone.lean) are defined by recursion on their height (`HasMistakeTree`); `hasMistakeTree_iff_exists_tree` relates them to explicit instance trees. `littlestoneDim` takes values in `ℕ∞` and is `0` for the empty class (Littlestone uses `-1`). The adversary lower bound is `littlestoneDim_le_mistakeBound`. The [standard optimal algorithm](../../CslibFrontier/MachineLearning/OnlineLearning/MistakeBound/SOA.lean) matches it, so `optimalMistakeBound_eq_littlestoneDim` holds for every class, finite or not. [Halving](../../CslibFrontier/MachineLearning/OnlineLearning/MistakeBound/Halving.lean) bounds finite classes by `⌊log₂ |C|⌋`. [VC dimension](../../CslibFrontier/MachineLearning/OnlineLearning/MistakeBound/VCDimension.lean) is at most the Littlestone dimension (`vcDim_le_littlestoneDim`). Because upstream `vcDim` is `0` for classes of infinite VC dimension, the meaningful statement for those is `littlestoneDim_eq_top_of_not_hasFiniteVCDim`. [Thresholds](../../CslibFrontier/MachineLearning/OnlineLearning/MistakeBound/Thresholds.lean) show the gap: VC dimension `1`, Littlestone dimension `⌊log₂ (N + 1)⌋` for `θ ≤ N`, and `⊤` for all thresholds on `ℕ`.

The [perceptron](../../CslibFrontier/MachineLearning/OnlineLearning/MistakeBound/Perceptron.lean) is an `OnlineLearner` on any real inner product space. Novikoff's bound `mistakes_perceptron_mul_sq_le` is stated per sequence, with margin `γ ≥ 0` and radius `R` as hypotheses on the presented examples. [Checked examples](../../CslibFrontierTests/MistakeBound.lean) run halving and the perceptron, compute the threshold gap, and show the bound failing for a negative margin.

[WINNOW1](../../CslibFrontier/MachineLearning/OnlineLearning/MistakeBound/Winnow.lean) learns monotone disjunctions `monotoneDisjunction R` on `Fin n → Bool`. Its weights are real numbers, the update factor `α` and threshold `θ` are real parameters, and `tie` fixes the prediction when the score equals `θ`, which the source leaves open. Littlestone's Theorem 7 is `mistakes_winnow_le`: for every sequence labelled by a disjunction of `k` variables, with `α > 1` and `α θ ≥ 1`, there are at most `α k (log_α θ + 1) + n / θ` mistakes, for every choice of `tie`. The [lower bound](../../CslibFrontier/MachineLearning/OnlineLearning/MistakeBound/MonotoneDisjunctions.lean) builds the shattered set of Littlestone's Lemma 6, giving `k ⌊log₂ (n / k)⌋` as a lower bound on both the VC dimension and the optimal mistake bound of `monotoneDisjunctions n k`. For `1 ≤ k ≤ n`, WINNOW1 with `α = 2` and `θ = n / k` makes at most `2 k log₂ (n / k) + 3 k` mistakes (`mistakeBound_winnow_two_div_le`, hence `optimalMistakeBound_monotoneDisjunctions_le`), so for `1 ≤ k` and `2 k ≤ n` the optimal bound is `Θ(k log (n / k))`. The hypothesis `1 ≤ k` is needed: for `k = 0` the threshold is `0`, and WINNOW1 can err on the constant-false target. For `k > n` the class is empty. The source's second lower bound, stated in terms of `k (1 + log₂ (n / k))`, is not formalized. [Checked examples](../../CslibFrontierTests/Winnow.lean) run WINNOW1 through a promotion step and an elimination step and evaluate both bounds for `n = 8`, `k = 2`.

[Randomized learners](../../CslibFrontier/MachineLearning/OnlineLearning/MistakeBound/Randomized.lean) map the history and the instance to a `PMF Bool`. Against a labelled sequence fixed in advance (an oblivious adversary), `expectedMistakes A S` sums the probabilities of wrong predictions; deterministic learners embed with `expectedMistakes = mistakes`. `hedgeLearner η E` draws one of finitely many deterministic experts with the Hedge distribution of the [multiplicative-update core](../../CslibFrontier/MachineLearning/OnlineLearning/MultiplicativeUpdate.lean) for their 0-1 losses, recomputed from the history. `expectedMistakes_hedgeLearner_le` transfers `hedge_regret_le_sqrt`: with the tuned rate `η = √(log N / T)` for `N` experts, on every sequence of at most `T` rounds and with `log N ≤ T`, the expected mistakes exceed those of every expert by at most `2 √(T log N)`.

[Agnostic online learning](../../CslibFrontier/MachineLearning/OnlineLearning/MistakeBound/Agnostic.lean) drops realizability: the labels are arbitrary and the learner competes with the best concept of `C`. Following Ben-David, Pál and Shalev-Shwartz (COLT 2009, §3.2, Algorithm 3), the expert `flipExpert (soa C) I` runs SOA on its own predictions, negated at the rounds in `I`. For each concept `c ∈ C`, negating at SOA's mistakes on the `c`-labelling (at most `littlestoneDim C` rounds) reproduces `c` exactly (`mistakes_flipExpert_mistakeRounds`; the source's Lemma 12 and Corollary 13). `agnosticSOA C T d` (Algorithm 4) runs Hedge over the at most `(T + 1)^d` sets of at most `d` rounds below `T`. `expectedMistakes_agnosticSOA_le`, the upper half of the source's Theorem 1 in its Littlestone-dimension form, bounds its expected mistakes by those of any `c ∈ C` plus `2 √(T d log (T + 1))` when `littlestoneDim C ≤ d`. The source's constant is `√(½ d T ln T)`; the one here comes from the library's Hedge bound, and the source's `ln |C|` branch for finite classes is not stated. The learner needs `T` and `d` in advance. Cover's observation (1965, as cited by the source), `exists_mistakes_eq_length_of_const_mem`, shows that randomization is necessary: against `Adversary.cover`, which negates each prediction, every deterministic learner errs in all `n` rounds, while if `C` contains both constant classifiers one of them errs in at most `n / 2`. The matching lower bound `Ω(√(Ldim(C) T))` for randomized learners and adaptive adversaries are not formalized. [Checked examples](../../CslibFrontierTests/AgnosticOnline.lean) compare the two over `100` rounds for the two constant classifiers.

These are information-theoretic statements. `soa` decides emptiness and compares Littlestone dimensions classically, WINNOW1 updates real weights, the agnostic learner enumerates its experts and weighs them with real arithmetic, and no learner here has a charged running time.

## Online convex optimization

[Online gradient descent](../../CslibFrontier/MachineLearning/OnlineLearning/OnlineGradientDescent.lean) plays points of a set `K` in a real inner product space. Its iterates are `x (t + 1) = proj (x t - η t • grad t (x t))`, where `grad : ℕ → E → E` is an arbitrary subgradient oracle. Rounds are indexed from `0`, so `η t` is the source's `η_{t+1}`. The projection is any map with `IsPythagoreanProjection K proj`: it lands in `K` and satisfies `‖proj y - z‖ ≤ ‖y - z‖` for `z ∈ K`. The [metric projection](../../CslibFrontier/Foundations/Analysis/InnerProductSpace/MetricProjection.lean) onto a nonempty complete convex set is such a map; that module also proves the variational characterization, the fixed points and nonexpansiveness. Losses enter only through the subgradient inequality `f t x + ⟪grad t x, y - x⟫ ≤ f t y` on `K`, or its `α`-strongly convex strengthening. [First-order convexity](../../CslibFrontier/Foundations/Analysis/Convex/FirstOrder.lean) derives both from Mathlib's `ConvexOn` and `StrongConvexOn` with `HasGradientWithinAt K` (so boundary points of `K` are allowed) or `HasGradientAt`.

Each regret bound holds against every comparator `u ∈ K`, under the hypotheses that `D` bounds the diameter of `K` and `G` bounds the subgradient norms on `K`. `ogd_regret_le_three_halves` is Hazan's Theorem 3.1: step sizes `D / (G √(t + 1))` give regret at most `3 / 2 · G D √T` for every `T`, assuming `D, G > 0`. `ogd_regret_le_zinkevich` is Zinkevich's Theorem 1, and `ogd_regret_le_fixed` gives `G D √T` (with `D, G > 0`) for a known horizon; both assume `T ≥ 1`. `ogd_regret_le_log` is Hazan's Theorem 3.3: for `α > 0`, `α`-strongly convex losses and step sizes `1 / (α (t + 1))` give `G² / (2α) · (1 + log T)`. It assumes no separate diameter bound, because its hypotheses already force `‖x - y‖ ≤ 2G / α` on `K` (`norm_sub_le_of_strongConvex`). OGD is deterministic, so these bounds also cover adaptive adversaries. [Checked examples](../../CslibFrontierTests/OnlineGradientDescent.lean) instantiate the bounds on `[-1, 1]` with linear and quadratic losses, and show maps that are not Pythagorean projections. As with the experts setting, nothing charges the cost of projections or arithmetic.

[Follow the regularized leader](../../CslibFrontier/MachineLearning/OnlineLearning/FTRL.lean) works in any real normed space. `IsFTRL K ψ ℓ x` says that every `x t` lies in `K` and minimizes `ftrlObjective ψ ℓ t = ψ + ∑ s < t, ℓ s` on `K`. The regularizer `ψ` is fixed, and rounds are indexed from `0`. The predicate constrains the realized sequence, and `x t` depends only on earlier losses, so the bounds also cover adaptive adversaries. `exists_isFTRL` gives runs on nonempty compact `K` when `ψ` and the losses are continuous on `K`. `IsFTRL.unique` shows they are unique when `ψ` is `μ`-strongly convex with `μ > 0` and the losses are convex. `ftrl_regret_eq` is Orabona's Lemma 7.1 and holds for every sequence. `IsFTRL.add_sum_le` and `IsFTRL.regret_le_add_sum_sub` are Hazan's Lemmas 5.4 and 5.3. The headline `IsFTRL.regret_le` assumes `ψ` is `μ`-strongly convex on `K` with `μ > 0` (Mathlib's `StrongConvexOn`, for the ambient norm), the losses are convex and `ℓ t (x t) - ℓ t y ≤ L t * ‖x t - y‖` on `K`. It bounds the regret against `u ∈ K` by `ψ u - ψ (x 0) + ∑ t < T, L t ^ 2 / (2μ)`. Its per-round step is the stability bound `StrongConvexOn.sub_le_of_isMinOn` in [strongly convex functions](../../CslibFrontier/Foundations/Analysis/Convex/Strong.lean), proved from quadratic growth at a minimizer without subgradients. The positivity matters: `StrongConvexOn K 0 ψ` is plain convexity, and with `μ = 0`, `ψ = 0` the displayed bound is false. `IsFTRL.regret_le_div` (regularizer `R / η` for a `σ`-strongly convex `R`, with `σ, η > 0`) is the constant-learning-rate case of Orabona's Corollary 7.9. `IsFTRL.regret_le_sqrt` tunes `η` to get `D L √(2T / σ)` when `σ, D, L > 0`, `T ≥ 1`, `R y - R z ≤ D ^ 2` for `y, z ∈ K`, and every round has the same `L`. `IsFTRL.regret_le_of_subgradient` and `IsFTRL.regret_le_of_hasFDerivWithinAt` cover FTRL on linearized losses with the operator norm of the subgradient. In a real inner product space, for a nonempty complete convex `K` and `η > 0`, `isFTRL_euclidean_iff` shows that the regularizer `‖y - x₀‖ ^ 2 / (2η)` with linear losses gives the metric projection of `x₀ - η ∑ s < t, g s` (lazy projection, Hazan §5.4.1). `lazyOGD` runs it with gradients chosen at the played points. When the gradients satisfy the subgradient inequality `f t x + ⟪grad t x, y - x⟫ ≤ f t y` on `K`, `lazyOGD_regret_le` bounds the regret against `u ∈ K` by `‖u - x₀‖ ^ 2 / (2η) + η / 2 ∑ t < T, ‖grad t (x t)‖ ^ 2`. `lazyOGD_regret_le_fixed` takes `η = D / (G √T)` and gives `G D √T` when, in addition, `D, G > 0`, `‖grad t x‖ ≤ G` on `K`, `‖u - x₀‖ ≤ D` and `T ≥ 1`. [Checked examples](../../CslibFrontierTests/FTRL.lean) compute a run on `[-1, 1]`, show a sequence that is not a run, and instantiate each bound. Time-varying regularizers, entropic FTRL (Hedge), mirror descent and the lower bounds are not formalized yet.

## Property testing as decision trees

The existing BLR local test compiles to a decision tree through `PCP.LocalTest.decisionTree`. [depth_decisionTree_repeatAll_blrTest_le](https://github.com/cslib-community/cslib-frontier/blob/13e6a31951bf1c89a1a6258c44f9444aecbbefd8/Complexity/Computability/PropertyTesting/Linearity.lean#L52) proves that k independent repetitions use at most 3k queries, accept every parity with probability one and accept a function at uniform relative Hamming distance at least epsilon from every parity with probability at most `(1-epsilon)^k`.

The corresponding [one-sided lower bound](https://github.com/cslib-community/cslib-frontier/blob/13e6a31951bf1c89a1a6258c44f9444aecbbefd8/Complexity/Computability/PropertyTesting/LinearityLowerBound.lean) shows that a tester of depth at most two that accepts every parity perfectly cannot reject the specified nonlinearity witness with value false at zero. This establishes the three-query boundary under those hypotheses. It is a lower bound for worst-case query depth, not expected queries, and it is formulated for arbitrary randomness support through the tested tree property.

The Fourier analysis behind these bounds lives in [BooleanAnalysis/Linearity](../../CslibFrontier/Foundations/BooleanAnalysis/Linearity.lean): `blrAcceptance_eq_sum_fourierCoeff_pow_three` and soundness `exists_hammingDist_parityOn_le_of_le_blrAcceptance` (O'Donnell, Theorem 1.30 [odonnell14]). [LinearityRejection](../../CslibFrontier/Foundations/BooleanAnalysis/LinearityRejection.lean) proves the converse rejection bound of O'Donnell's Exercise 1.28. If `f` is at relative distance `δ` from the parity on `T`, every other coefficient of `(-1)^f` has absolute value at most `2δ` (`abs_fourierCoeff_signVal_le_of_ne`). The test then accepts with probability at most `1 - 3δ + 10δ² - 8δ³` (`blrAcceptance_le_of_hammingDist_parityOn`); this holds for any parity, not only the nearest. The constant `3` is sharp: the indicator of a nonzero point on `n ≥ 2` bits is at distance `δ = 2⁻ⁿ` from its nearest parity and is rejected with probability exactly `3δ - 6δ²` (`blrAcceptance_decide_eq`). Hence, for every `c > 3`, no bound `cδ - Cδ²` holds for all functions at small distance from their nearest parity (`not_forall_mul_sub_mul_sq_le_one_sub_blrAcceptance`). [Affinity](../../CslibFrontier/Foundations/BooleanAnalysis/Affinity.lean) covers Exercise 1.29, with affine functions written `b ^^ parityOn S x`. They are characterized by `f (x + y + z) = (f x ^^ f y ^^ f z)` (`exists_eq_xor_parityOn_iff`) and by `f (x + y) = (f x ^^ f y ^^ f 0)` (`exists_eq_xor_parityOn_iff_add`). The four-query test with uniform queries `x`, `y`, `z`, `x + y + z` accepts with probability `1/2 + 1/2 Σ_S F̂(S)⁴` (`affinityAcceptance_eq_sum_fourierCoeff_pow_four`). Affine functions pass with probability one, and acceptance at least `1 - ε` gives an affine function at relative distance at most `ε` (`exists_hammingDist_xor_parityOn_le_of_le_affinityAcceptance`). The anchored variant replaces the fourth query by the point `0`; it is the BLR test on `x ↦ f x ^^ f 0` (`anchoredAffinityAcceptance_eq_blrAcceptance`) and has the same guarantees. Both acceptance probabilities are expectations over the cube; neither test is packaged as a `PCP.LocalTest` with query-depth bounds yet. The [checked examples](../../CslibFrontierTests/BooleanAnalysisLinearityTesting.lean) include a three-bit point indicator rejected with probability `9/32`, strictly between the cubic bound `15/64` and `3δ = 3/8`. They also include the conjunction of two bits, which attains the coefficient bound and passes the affinity test with probability `5/8`, and a negated parity that both affinity tests accept and the BLR test always rejects.

## Monotonicity testing

[Monotonicity/Basic](../../CslibFrontier/Computability/PropertyTesting/Monotonicity/Basic.lean) works on the cube `ι → Bool` for a finite index type `ι` (for example `Fin n`), with Mathlib's coordinatewise order and Mathlib's `Monotone`. `monotone_iff_forall_update_le` reduces monotonicity to the edges `update x i false ≤ update x i true`. `violatedEdges f i` lists, by their lower endpoints, the edges in direction `i` along which `f` decreases. Below, `A_i = violatedEdges f i`. `f` is monotone exactly when there are none (`monotone_iff_forall_violatedEdges_eq_empty`). `distMonotone f` is the least Hamming distance from `f` to a monotone function, and `relDistMonotone f` divides it by `2 ^ n`. "`f` is `ε`-far from monotone" is stated as `ε ≤ relDistMonotone f`: every monotone function differs from `f` on at least `ε 2 ^ n` points (`le_relDistMonotone_iff`). `violatedEdgeFraction f` is `Σ_i |A_i|` divided by the `n 2 ^ (n - 1)` edges of the cube.

The squashing operator `sortAlong i f` sorts the values of `f` along every edge in direction `i`. It changes `f` at exactly the `2 |A_i|` endpoints of the violated edges in that direction (`hammingDist_sortAlong`) and leaves no violated edge there (`violatedEdges_sortAlong_self`). The Key Claim of the source's proof is `card_violatedEdges_sortAlong_le`: sorting along `i` does not increase the number of violated edges in any direction `j`. It is proved by checking the 16 labellings of each square spanned by `i` and `j`. Sorting along every direction in turn gives a monotone function within distance `2 Σ_i |A_i|` (`distMonotone_le_two_mul_sum`). Hence an `ε`-far function has at least an `ε / n` fraction of violated edges (`div_card_le_violatedEdgeFraction`). In the other direction, `card_violatedEdges_le_distMonotone` gives `|A_i| ≤ distMonotone f`.

The [edge tester](../../CslibFrontier/Computability/PropertyTesting/Monotonicity/EdgeTester.lean) reuses the BLR format: `edgeTest ι` is a two-query `PCP.LocalTest` with random string `(i, x)`. It reads `f` at both endpoints of the edge in direction `i` through `x` and accepts when `f` does not decrease along it. One trial rejects with probability exactly `violatedEdgeFraction f` (`one_sub_acceptProb_edgeTest`). `k` independent trials make at most `2k` non-adaptive queries (`depth_decisionTree_repeatAll_edgeTest_le`) and always accept monotone functions (`acceptProb_repeatAll_edgeTest_of_monotone`). They accept `ε`-far functions with probability at most `(1 - ε / n) ^ k` (`acceptProb_repeatAll_edgeTest_le`), hence at most `1/3` once `0 < ε` and `2n ≤ εk` (`acceptProb_repeatAll_edgeTest_le_one_third`). `acceptProb_repeatAll_edgeTest_ceil_le_one_third` takes `k = ⌈2n / ε⌉`, so the tester makes `2 ⌈2n / ε⌉` queries. This is the upper bound of Theorem 8.2 in Roughgarden's lecture notes ([roughgarden15cc]), which attributes the tester to Goldreich, Goldwasser, Lehman, Ron and Samorodnitsky ([gglrs00]); the proof follows those notes. The theorem takes `t = Θ(n / ε)` trials. Only the upper bound is formalized, with the explicit choice `t = ⌈2n / ε⌉`; nothing is claimed about fewer trials. The completeness theorems need `Nonempty ι`: the cube of dimension `0` has no edges, and an expectation over an empty set of random strings is `0` by convention. These are query bounds only; no running time is claimed. Three published results are not formalized here: the `Ω(√n)` lower bound for non-adaptive one-sided testers, the testers for larger ranges and hypergrids, and the `Õ(√n / ε²)` path testers. The [checked examples](../../CslibFrontierTests/PropertyTestingMonotonicity.lean) include:
- a monotone function on `Fin 2` that is always accepted;
- the anti-dictator `x ↦ ¬x₀` on `Fin 3`, with four violated edges, distance `4`, relative distance `1/2` and single-trial acceptance probability `2/3`;
- a tester with twelve trials at proximity `1/2`;
- an example showing that one trial is too few.

## Distribution testing from samples

[IsTester](../../CslibFrontier/Computability/PropertyTesting/Distribution/Basic.lean) is the sample-access model. A `k`-sample tester for a set `P` of distributions on a finite type is a randomized rule `T : (Fin k → α) → PMF Bool`. It runs on `iid p k` and must accept every member of `P` with probability at least 2/3. It must accept with probability at most 1/3 every `p` whose statistical distance (`dist`, total variation) from every member of `P` is at least epsilon. The metric space on `PMF α` is a scoped instance, so `dist` needs `open Cslib.Probability.PMF` (or `open scoped Cslib.Probability.PMF`). Testers are semantic kernels: the theorems count samples, not running time. `one_third_le_dist_iid_bind` is Le Cam's method in mixture form, and `IsTester.map_equiv` relabels the domain. It rests on `abs_bind_apply_toReal_sub_le_dist` in [StatisticalDistance/Event](../../CslibFrontier/Probability/StatisticalDistance/Event.lean): a randomized distinguisher's output probabilities move by at most the statistical distance.

The [collision tester](../../CslibFrontier/Computability/PropertyTesting/Distribution/UniformityCollision.lean) accepts when the number of colliding sample pairs is at most `C(k,2)(1+2ε²)/n`. Under `40 √n ≤ (k-1) ε²` and `0 < ε`, `isTester_collisionTester` proves it is a uniformity tester. The proof applies the finite Chebyshev inequality `sum_mul_ite_le_sum_mul_sq_div` from [Probability/PMF/Chebyshev](../../CslibFrontier/Probability/PMF/Chebyshev.lean) to the exact mean and variance of `collisionCount` from [Probability/IID/CollisionCount](../../CslibFrontier/Probability/IID/CollisionCount.lean). Paninski's [lower bound](../../CslibFrontier/Computability/PropertyTesting/Distribution/UniformityLowerBound.lean) `card_le_of_isTester_uniform` gives `n ≤ 52 k² δ⁴` for every tester with proximity `δ ≤ 1/2` on a domain of even size `n`. At `δ = 1/2` it is the birthday bound `4n ≤ 13k²`. The odd-size lower bound and tolerant testing remain open. The [checked examples](../../CslibFrontierTests/DistributionTestingUniformity.lean) include a satisfiable instance of the sample hypothesis, a far distribution and an impossible single-sample tester.

[Identity testing](../../CslibFrontier/Computability/PropertyTesting/Distribution/IdentityReduction.lean) to a fixed distribution `q` on `n` points reduces to uniformity testing. `IsTester.bind_pi` in [Basic](../../CslibFrontier/Computability/PropertyTesting/Distribution/Basic.lean) runs a tester on samples passed independently through a randomized map `F`. It requires that `F` sends the property into the target property and far distributions to far distributions, and it rests on `iid_bind` in [Probability/IID](../../CslibFrontier/Probability/IID.lean). Goldreich's kernel `identityKernel q` maps `q` exactly to uniform on the `4n` cells of `IdentityDomain q` (`bind_identityKernel_self`). It shrinks statistical distance by at most a factor 3 (`dist_le_three_mul_dist_bind_identityKernel`). Hence `isTester_identity_of_uniform`: a uniformity tester on the cells with proximity `ε/3` tests identity to `q` with proximity `ε` and the same number of samples. `exists_isTester_identity_of_uniform` accepts a uniformity tester on any domain of size `4n`. With the collision tester, `isTester_identityTester` needs `0 < ε` and `720 √n ≤ (k-1) ε²`. The [checked examples](../../CslibFrontierTests/DistributionTestingIdentity.lean) compute block sizes, including a nonempty and an empty leftover block, and a satisfiable sample-size instance.

[Closeness testing](../../CslibFrontier/Computability/PropertyTesting/Distribution/ClosenessCollision.lean) compares two unknown distributions. In the two-sample model in [Basic](../../CslibFrontier/Computability/PropertyTesting/Distribution/Basic.lean), a rule `T : (Fin k → α) → (Fin k → α) → PMF Bool` gets `k` samples of each distribution, with acceptance probability `acceptProb₂ T p q`. `IsClosenessTester T ε` requires acceptance probability at least `2/3` when `p = q`, and at most `1/3` when `ε ≤ dist p q`. The collision statistic `closenessStatistic x y = C₁ + C₂ - ((k-1)/k) C₃` combines the self-collisions of each sample with the cross-collisions `crossCollisionCount` from [Probability/IID/CrossCollisionCount](../../CslibFrontier/Probability/IID/CrossCollisionCount.lean). Its mean is `C(k,2) ‖p-q‖₂²` (`sum_sum_iid_mul_closenessStatistic`), and its variance has an exact closed form (`sum_sum_iid_mul_closenessStatistic_sub_sq`). When both collision probabilities are at most `b`, that closed form is bounded by `(k-1)(2k-1) b + 2(k-1)²(k+1) √b ‖p-q‖₄²` (`sum_sum_iid_mul_closenessStatistic_sub_sq_le_sqrt_sum_pow_four`, which implies DGPP's Lemma 10), and hence by the same expression with `‖p-q‖₂²` (`sum_sum_iid_mul_closenessStatistic_sub_sq_le`). The tester `closenessTester k ε` accepts when the statistic is at most `C(k,2) ε²/2`. `le_acceptProb₂_closenessTester` and `acceptProb₂_closenessTester_le` show it errs with probability at most `δ` on each side once `0 < δ` and `36 √b ≤ (k-1) ε² δ`. The hypotheses are the squared distances `‖p-q‖₂² ≤ ε²/4` and `ε² ≤ ‖p-q‖₂²`; for `0 < ε` this distinguishes `‖p-q‖₂ ≤ ε/2` from `‖p-q‖₂ ≥ ε`. `isClosenessTester_closenessTester` turns this into a closeness tester in statistical distance under `0 < ε` and `27 n ≤ (k-1) ε²`. That is `O(n/ε²)` samples, which is not optimal: learning both distributions empirically to statistical distance `ε/4` and comparing achieves the same rate. The optimal tester applies the `ℓ₂` tester after flattening. Statistical distance `dist` needs `open Cslib.Probability.PMF` (scoped instance). The [checked examples](../../CslibFrontierTests/DistributionTestingCloseness.lean) include exact cross-collision counts and means, an `ℓ₂` instance using `√b = 1/2`, and a closeness tester on `Bool` with `217` samples that rejects two distinct point masses.

[Flattening](../../CslibFrontier/Computability/PropertyTesting/Distribution/ClosenessFlattening.lean) gives the optimal closeness tester. The split distribution `split p c` in [Probability/Split](../../CslibFrontier/Probability/Split.lean) divides each point `a` into `c a + 1` equal cells. It preserves statistical distance (`dist_split`). Its collision probability `∑ p(a)² / (c a + 1)` is antitone in `c` (`collisionProbability_split_antitone`). When `c` counts the occurrences in `m` independent samples of `p` itself, the expected collision probability is at most `1/(m+1)` (`sum_iid_mul_collisionProbability_split_le`). That rests on the inverse occurrence moment `(m+1) μ(a) E[1/(N+1)] ≤ 1` in [Probability/IID/Occurrence](../../CslibFrontier/Probability/IID/Occurrence.lean), which also holds `occurrenceCount` and the splitting lemmas `sum_iid_succ_mul` and `sum_iid_add_mul` for independent draws.

`closenessFlatteningTester m k ε` draws `m + k` samples of each distribution. The first `m` of both set `c = flatteningCount x₁ y₁`, the combined occurrence counts, so the split domain has `n + 2m` points. The other `k` of each pass through the split kernel into `closenessTester k (2ε/√(n+2m))`. `acceptProb₂_append` and `acceptProb₂_bind_pi` in [Basic](../../CslibFrontier/Computability/PropertyTesting/Distribution/Basic.lean) reduce the acceptance probability to an average, over the flattening samples, of the `ℓ₂` tester's acceptance probability on the split distributions (`acceptProb₂_closenessFlatteningTester`). Markov's inequality at collision level `16/(m+1)` and `four_mul_dist_sq_le_card_mul_sum_sq` (Cauchy–Schwarz, in [Probability/Collision](../../CslibFrontier/Probability/Collision.lean)) then give `isClosenessTester_closenessFlatteningTester` under `0 < ε` and `864 (n + 2m) ≤ 5 (k-1) ε² √(m+1)`. With `m = ⌈min(n, n^{2/3} ε^{-4/3})⌉`, `exists_isClosenessTester_closenessFlatteningTester` gets `m + k ≤ 520 max(n^{2/3} ε^{-4/3}, √n ε^{-2}) + 3`. That is the Chan–Diakonikolas–Valiant–Valiant rate. The construction follows Diakonikolas–Kane Proposition 2.10 with two changes. It uses a fixed number of flattening samples instead of a Poisson number. It also flattens with samples of both distributions, so both split norms are small and the norm estimation of their Lemma 2.3 is not needed. The matching lower bound is not formalized. The [checked examples](../../CslibFrontierTests/DistributionTestingClosenessFlattening.lean) include split masses and domain sizes, a satisfiable instance on `100` points, and a tester on `Bool` that rejects two distinct point masses.

## Dense graph testing

[Dense graph testers](../../CslibFrontier/Computability/PropertyTesting/DenseGraph/Basic.lean) read a graph on `Fin n` through its adjacency matrix. A `Tester n` is a `ProbOracleComp` that tosses private coins and asks vertex-pair queries adaptively. `acceptProb T G` runs it against the deterministic adjacency oracle `adjOracle G`. `editDist G H` counts the unordered vertex pairs on which two graphs differ. `IsFar G P ε` requires every graph with property `P` to differ from `G` in more than `ε n²` pairs. Goldreich normalizes by the `n²` ordered matrix entries, so his proximity `ε` is `IsFar G P (ε / 2)` here. `IsOneSidedTester T P ε q` bundles a worst-case query bound (`ProbOracleComp.IsQueryBounded`), acceptance probability one on `P` and acceptance probability at most 1/3 on `ε`-far graphs. `OneSidedTestable P q` asks for such a tester with `q ε` queries for every `ε > 0` and every `n`. `IsFar.farFromTriangleFree` and `isFar_of_farFromTriangleFree` compare `IsFar` with Mathlib's deletion distance `SimpleGraph.FarFromTriangleFree`. `isOneSidedTester_repeatAll` amplifies a perfectly complete test that rejects far graphs with probability at least `δ` by `k` repetitions with `2 ≤ δ k`. A new tester is written with `queryAdj` and `ProbOracleComp.sample`. `evalWith_queryAdj`, `adjOracle_apply` and the general `ProbOracleComp.evalWith_sumHandler_unifOracle_sample` evaluate its steps, `IsOneSidedTester.evalWith_false_eq_zero` says that a one-sided tester never rejects a graph with the property, `acceptProb_repeatAll` and `isQueryBounded_repeatAll` handle repetition with `OracleComp.repeatAll`, and `IsFar.deleteFar` and `isFar_of_deleteFar` compare `IsFar` with Mathlib's `DeleteFar` for any property.

The [triangle tester](../../CslibFrontier/Computability/PropertyTesting/DenseGraph/TriangleFree.lean) samples `k` uniform ordered vertex triples and queries their three pairs. It rejects when one sampled triple is a triangle. `acceptProb_triangleTester` gives its exact acceptance probability `(1 - 6 t / n³) ^ k` on a graph with `t` triangles. Mathlib's triangle removal lemma gives at least `triangleRemovalBound ε · n³` triangles in an `ε`-far graph. Hence `isOneSidedTester_triangleTester`: for `ε > 0` and `1 ≤ 3 · triangleRemovalBound ε · k`, the tester is one-sided with `3k` queries. `oneSidedTestable_cliqueFree_three` states the resulting bound `3 ⌈(3 · triangleRemovalBound ε)⁻¹⌉`, independent of `n`. Its constant is the tower-type constant of the regularity lemma. The theorems count queries, not running time. General `H`-freeness remains open. The [checked examples](../../CslibFrontierTests/DenseGraphTesting.lean) include a far graph on three vertices and a one-sided tester with explicit parameters (five trials, 15 queries, proximity 1/10). They also show that one trial is too few.

The [bipartiteness tester](../../CslibFrontier/Computability/PropertyTesting/DenseGraph/Bipartite.lean) follows Goldreich–Goldwasser–Ron. `bipartiteTester n s m` samples `s` uniform vertices `u` and `m` uniform vertex pairs `(x k, y k)`, independently. It queries the `m (2 s + 1)` pairs `(x k, u i)`, `(y k, u i)` and `(x k, y k)`, and accepts when the sample positions admit a proper 2-colouring (`bipAccept`). Colours are attached to positions, so a vertex sampled twice may receive two colours. This is laxer than asking that the observed subgraph be bipartite: with `s = 0` and `m = 3` the tester can observe a triangle and still accept. `acceptProb_bipartiteTester_eq_one` is perfect completeness: a 2-colouring of the graph induces one of the sample positions. `IsFar.two_mul_lt_sum_monochromatic` states that a graph `ε`-far from bipartite has more than `2 ε n²` ordered monochromatic adjacent pairs under every 2-colouring. Soundness, `acceptProb_bipartiteTester_le_one_third`, assumes `12 ≤ ε s` and `s + 3 ≤ ε m`. In its proof, a colouring of `u` forces the colour of every vertex with a neighbour in `u`. Markov's inequality bounds the probability of a large degree mass outside the neighbourhood of `u` by `2 / (ε (s + 1))`. This expectation bound replaces the coverage step of Goldreich–Goldwasser–Ron (§6.1, Theorem 6.1.2 and Claims 6.1.4 and 6.1.6), which uses a sample of `O(log (1 / (ε δ)) / ε)` vertices and `O(log² (1 / (ε δ)) / ε³)` queries. The refinement removes the logarithmic factors. It is our adaptation, with no exact source and no claim of novelty. A union bound over the `2 ^ s` colourings of `u` bounds the rest by `2 ^ s (1 - ε) ^ m`. `isOneSidedTester_bipartiteTester` bundles these with the query bound, and `oneSidedTestable_isBipartite` fixes `s = ⌈12 / ε⌉` and `m = ⌈(s + 3) / ε⌉`. `bipartiteQueryBound_le` bounds the resulting query count by `459 / ε³` for `0 < ε ≤ 1`. That is polynomial in `1 / ε` and independent of `n`, but weaker than the `Õ(ε⁻²)` queries that follow from the `Õ(1 / ε)`-vertex sample analysis of Alon and Krivelevich. The [checked examples](../../CslibFrontierTests/DenseGraphTestingBipartite.lean) show that the triangle is `1/10`-far from bipartite and is rejected by the tester with `s = 120` and `m = 1230`. They also show that `s = m = 0` accepts every graph, and they evaluate the query bound at `ε = 1/10` (296430 queries).

[Canonical testers](../../CslibFrontier/Computability/PropertyTesting/DenseGraph/Canonical.lean) formalize the one-sided half of Goldreich–Trevisan's Theorem 2 (Theorem 4.5). A property `P` of graphs on `Fin n` is `IsInvariant` when it is closed under relabelling. Then `IsFar.comap` (their Claim 2.1, from `editDist_comap_equiv`) says that relabelling preserves the distance to `P`. `canonicalTester n s hs D` samples a uniform permutation `σ`, queries all pairs among `σ 0, …, σ (s - 1)` (`queryInduced`) and accepts exactly when the induced labelled graph on `Fin s` has property `D`. It makes `s.choose 2` queries (`isQueryBounded_canonicalTester`), and `acceptProb_canonicalTester` gives its acceptance probability as an event over `σ`. `InducedOf P K` says that `K` is an induced subgraph (`K ⊴ H`) of some graph `H` with property `P`; it is itself invariant (`isInvariant_inducedOf`). `acceptProb_canonicalTester_eq_one_iff` shows that a canonical tester is perfectly complete on `P` exactly when `D` contains `InducedOf P`. The main theorem, `isOneSidedTester_canonicalTester`, takes a one-sided tester with `q` queries for an invariant `P` (adaptive or not). It gives the canonical tester with `min (2q) n` sample vertices and decision property `InducedOf P`, which is one-sided for `P` with the same proximity and `(2q).choose 2` queries. `OneSidedTestable.canonical` states this for families. The proof runs the original tester against a lazily sampled relabelling (`Cslib.RandomPermutation`) and uses induction on the query bound in place of the paper's vertex-uncovering tester. The proximity enters only through `IsFar.comap`, so the result does not depend on how the distance is normalized. Limitations: the two-sided half (`O(q)` sample vertices after error reduction and their Lemma 4.4) is not formalized. The decision property `InducedOf P` depends on `n`, as the paper allows. Deciding by `P` itself (their §4.2.4, Proposition D.2 and Corollary 5.9) is not addressed. The theorems count queries, not running time. The [checked examples](../../CslibFrontierTests/DenseGraphTestingCanonical.lean) show that triangle-freeness is invariant and derive the canonical triangle tester from `oneSidedTestable_cliqueFree_three`. On three vertices the canonical tester rejects the triangle with certainty and accepts the empty graph. Of two trivial decision properties, rejecting everything is not perfectly complete and accepting everything is. With two sample vertices the triangle is accepted with certainty, so that tester is not sound. For the labelled property "`0` and `1` are adjacent", which is not invariant and has a one-query one-sided tester, the canonical tester accepts the far empty graph with certainty, so the invariance hypothesis is needed.

## Known Limitations

The examples use semantic hypotheses and real probability/analysis. These results provide formal sample/query guarantees and formal bridges to PAC/query models. Claims of polynomial native training time or succinct executable output hypotheses require separate resource theorems. Keep these limitations in view when choosing a learning model: the notions of efficiency differ.

## Replicable algorithms

Shared-seed replicable sample algorithms ([Impagliazzo–Lei–Pitassi–Sorrell 2022](../sources.md#ilps22), formalized in [`Basic.lean`](../../CslibFrontier/MachineLearning/Replicable/Basic.lean)) capture randomized algorithms `Algorithm X Ω α m` whose shared seed `r : Ω` fixes a common source of randomness across two independent runs on fresh i.i.d. `m`-sample draws from a distribution `D : PMF X`.

* **Core interface and `ProbComp` programs**: [`Basic.lean`](../../CslibFrontier/MachineLearning/Replicable/Basic.lean) defines `Algorithm`, `ProbComp`-backed [`Program`](../../CslibFrontier/MachineLearning/Replicable/Basic.lean) (whose `Program.toAlgorithm` lowers `seed` and `run` semantically via `ProbComp.eval`), weak family-restricted replicability `IsReplicableFor`, distribution-free strong replicability `IsReplicable`, and accuracy predicates `IsAccurateFor`, `EstimatesFor`, and `Estimates`.
* **Composition**: [`Composition.lean`](../../CslibFrontier/MachineLearning/Replicable/Composition.lean) proves additive replicability preservation under sequential pairing (`seqPair`), sequential binding (`seqBind`), product families (`pi`), and `k`-fold replication (`replicate`).
* **Randomized rounding**: [`Rounding.lean`](../../CslibFrontier/MachineLearning/Replicable/Rounding.lean) provides discrete randomized threshold rounding (`thresholdRound`, ideal real-arithmetic `thresholdProg`), periodic offset-grid rounding (`roundGrid`, `roundGridProg`), continuous `[0, 1)` Lebesgue-measure equivalents, and generic concentration-to-replicability theorems (`isReplicableFor_roundGridProg_of_concentrates`, `isAccurateFor_roundGridProg_of_concentrates`).
* **Confidence and replicability amplification**: [`Amplification.lean`](../../CslibFrontier/MachineLearning/Replicable/Amplification.lean) formalizes `majorityVote` and `medianOfRuns` confidence amplification (`β₀ < 1 / 2`), finite-domain heavy-hitter amplification (`amplifyFinite`) yielding strong `ρ`-replicability from accuracy `β₀ < 1 / (|α| + 1)`, and general-domain collision-threshold amplification (`amplifyReplicability`) boosting any `ρ₀ < 1 / 2` over `[DecidableEq α]` while preserving `(good, β)` accuracy (`isAccurateFor_amplifyReplicability`, `exists_amplifyReplicability_accurate`) whenever the input algorithm satisfies an `O(β / T)` initial-error bound (since `pickFirstThresholded` selects a single passing candidate seed rather than amplifying error from `≈ 1 / 2`).
* **Bounded-mean and coin bias clients**: [`BiasEstimation.lean`](../../CslibFrontier/MachineLearning/Replicable/BiasEstimation.lean) defines the `ProbComp`-backed ideal real-arithmetic programs `replicableMeanProg` and `replicableBiasProg`, combining Hoeffding concentration with `roundGridProg` to obtain strong `ρ`-replicability and `(ε, β)`-accuracy under `Program.toAlgorithm`.

Checked counterexamples (including exact `disagreeProb = 1 / 2` on a fair coin and weak-vs-strong replicability separation) and concrete instantiations live in [`Replicable.lean`](../../CslibFrontierTests/Replicable.lean). Note on scope: `Program` here interprets `ProbComp` computations into semantic `Algorithm`s (`Program.toAlgorithm`); `thresholdProg`, `roundGridProg`, `replicableMeanProg`, and `replicableBiasProg` are `noncomputable` ideal real-arithmetic specifications (using arbitrary real estimators, real comparisons, and real floor), so finite-representation/precision realizations and native computational resource bounds remain open.
