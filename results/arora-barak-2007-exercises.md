# Arora–Barak draft exercise inventory

Audit: Christian Reitwiessner, with Claude Code assistance.

This inventory classifies every end-of-chapter exercise of the
[public web draft dated 2007-01-08](https://theory.cs.princeton.edu/complexity/book.pdf)
(SHA-256 `da0881782a35bde6a0779a2eb1a8d480f39fbddf70bbb92824d1dc5550a033b2`), the source of the
[chapter audit](arora-barak-2007.md), under [#4711](https://github.com/cslib-community/cslib-frontier/issues/4711).
Chapter 14's six exercises are classified in that audit's
[exercise table](arora-barak-2007.md#exercises-establishing-new-theory) and are not repeated here.
Christian Reitwiessner's scope includes exercises that establish new theory; routine practice is
not a formalization target. Numbers and printed pages belong to the draft, not the published
edition; printed page = PDF page − 16 throughout. Chapter 18 heads its exercises “Problems”;
Chapter 21 has none.

Each exercise, or each subpart where subparts differ, has one class:

- **T**: establishes new theory: a named theorem, a class relation, a construction or bound reused
  later, a characterization, or a step the main text delegates to the exercise. **Partial** marks
  library results that cover part of the endpoint; the row says what remains.
- **C**: covered by the cited library declarations in a model the chapter audit accepts, with
  the stated qualifications.
- **S**: source specification needed or source issue: a placeholder, an unresolved reference
  that leaves the statement undetermined, an open question, or a false statement. Where an evident
  repair exists, the row gives it as a **corrected endpoint** and classifies that.
- **R**: routine practice, listed in one line per chapter.
